# Text-Based Fishing Simulator

A feature-rich console game written in Python core during my 80th day of programming. **Fun fact: the entire logic of 241 lines was built in just one late night and 2 hours the next day.**

## Features
- **Object-Oriented Programming (OOP):** Separate classes for spinning and float fishing with real-time fish generation.
- **Dynamic Weight Logic:** Custom weight ranges for different fish species (e.g., specific small ranges for Bleak).
- **In-Game Economy:** Fully functional market with dynamic pricing based on fish weight thresholds.
- **Resource Management:** Durable gear mechanics including line snaps, losing bait, and buying custom hand-made tackle.
- **Error Handling:** Robust `try-except` blocks preventing application crashes on invalid menu choices or empty inventory lookups.
- **Real-Time Logs:** Automated time tracking for catches using the `datetime` module.

## Tech Stack
- Python 3.x
- Built-in modules: `random`, `time`, `datetime`
